# Agente especializado — Frontend ePoint CRM

Esta carpeta viaja con el repositorio. Si clonás solo el frontend en otra PC, el agente de Cursor tiene todo el contexto acá.

## Archivos

| Archivo | Uso |
|---------|-----|
| [`CONTEXT.md`](./CONTEXT.md) | Stack, rutas, features, i18n, API, deploy |
| [`RULES.md`](./RULES.md) | Reglas obligatorias al modificar código |

## Cómo usarlo en Cursor

1. Abrí la carpeta del repo (`epoint-central-frontend` o `frontend/`) como workspace.
2. El `AGENTS.md` de la raíz apunta acá.
3. Si falta contexto: *“Leé agent/CONTEXT.md y agent/RULES.md”*.

## Repo hermano

- Backend: `epoint-central-backend` → Heroku `dev-epoint-crm-backend`
- Mobile: `epoint-central-mobile`
- Este frontend: GitHub `epoint-central-frontend` → Heroku `dev-epoint-crm-frontend`
